# 뷰어 기능 상세

`docs/USAGE.md`의 "뷰어에서 다운로드한 작품 보기"를 보충하는 문서로, 뷰어 탭에 추가된
개별 기능을 자세히 설명합니다. 아래 기능은 모두 브라우저에서 동작하며(서버 쪽 상태는
`updated_at` 정렬용 폴더 수정시각 한 가지만 추가됨), 대부분 **브라우저의
`localStorage`에 저장**됩니다 — 즉 같은 브라우저에서만 유지되고, 다른 브라우저/기기나
시크릿 모드에서는 공유되지 않습니다.

## 검색 · 정렬

검색창은 지금 보고 있는 화면에 따라 검색 대상이 자동으로 바뀝니다. 정렬
드롭다운은 작품 목록에서만 나타납니다.

- **작품 목록 화면**: 검색창에 입력한 글자가 포함된 작품만 실시간으로 걸러
  보여줍니다(대소문자 구분 없음). 정렬은 `이름순`(기본값) / `최근
  다운로드순`(`downloads/{작품}/` 폴더 수정 시각 기준, 새로 받은 작품이
  위로) / `이미지 많은순`(전체 이미지 수 내림차순) 중에서 고를 수 있습니다.
- **회차 목록 화면**: 같은 검색창이 이번엔 회차 이름을 검색합니다 — 자리
  표시 문구도 "회차 검색 (예: 006)"으로 바뀝니다. 예를 들어 `006`을 입력하면
  "006화"(평면 다운로드 구조) 같은 회차만 남습니다. 정렬 드롭다운은 이
  화면에서는 의미가 없어 숨겨집니다.

검색·정렬은 서버에 다시 요청하지 않고 이미 받아온 목록을 그 자리에서 다시
필터링/정렬합니다. 화면을 옮기면(작품 목록 ↔ 회차 목록) 검색어는 초기화됩니다.
리더로 들어가면 검색창 자체가 숨겨집니다.

## 이어보기 / 읽음 표시

- 회차를 하나라도 열람하면 해당 작품·회차의 읽음 상태와 마지막으로 보던 위치가
  브라우저에 저장됩니다.
- **작품 카드**: 진행 기록이 있는 작품의 표지 오른쪽 위에 노란색 "이어보기" 배지가
  뜹니다. 누르면 회차 목록을 거치지 않고 바로 마지막으로 보던 회차의, 마지막으로
  스크롤했던 위치로 이동합니다.
- **회차 목록 화면**: 진행 기록이 있으면 상단에 "이어보기" 버튼이 한 번 더 뜨고,
  이미 읽은 회차 카드는 흐리게 표시되고 초록색 "읽음" 배지가 붙습니다.
- **읽음 처리 시점**: 리더에서 다음 회차로 스크롤이 넘어가는 순간(연속 스크롤이든
  "다음 화" 버튼이든) 방금 지나온 회차가 읽음으로 표시됩니다. 마지막 화의 끝까지
  스크롤하면 그 회차도 읽음 처리됩니다. 위로 스크롤해서 이전 내용을 다시 보는 것은
  읽음 상태에 영향을 주지 않습니다.
- 저장 폴더에서 회차가 삭제된 뒤라면 "이어보기"는 자동으로 그 작품의 첫 회차로
  대신 이동합니다.
- 회차 목록 화면과 리더 상단 바에는 항상 **"← 라이브러리"/"라이브러리"** 버튼이
  있어, 몇 단계를 거쳤든 클릭 한 번으로 작품 목록으로 바로 돌아갈 수 있습니다.
  (리더의 "목록으로"는 지금 보던 작품의 회차 목록으로만 돌아갑니다 — 둘의
  차이에 유의하세요.)

## 연속 스크롤 (자동 다음 화 로드)

리더에서 현재 회차의 끝 근처까지 스크롤하면, 다음 회차가 있는 경우 자동으로
이어서 불러와 스크롤을 계속할 수 있습니다. 회차가 바뀌는 지점에는 회차명이 적힌
구분선이 표시됩니다. 더 이상 다음 화가 없으면 "마지막 화입니다." 안내가 뜨고
더 이상 자동 로드하지 않습니다.

- 상단 바의 작품/회차 표시, 브레드크럼, "이전 화"/"다음 화" 버튼 활성 상태는
  현재 화면에 보이는 회차를 기준으로 자동 갱신됩니다.
- "다음 화" 버튼을 눌렀을 때 그 회차가 이미 자동으로 불러와져 있으면(스크롤로
  이미 지나온 경우) 다시 내려받지 않고 해당 구분선으로 부드럽게 스크롤만 합니다.
- 자동 로드는 **앞으로만** 동작합니다. "이전 화"는 항상 새로 불러옵니다(뒤로
  이어붙이는 무한 스크롤은 지원하지 않음).

## 보기 모드: 웹툰(세로 스크롤) ↔ 페이지 넘김

리더 상단 바의 "웹툰 모드로 보기" / "페이지 넘김으로 보기" 버튼으로 두 가지
읽기 방식을 전환할 수 있습니다. 선택한 모드는 브라우저에 저장되어 다음에
리더를 열 때도 유지됩니다.

- **웹툰 모드** (기본값): 지금까지의 세로 연속 스크롤 방식. 이미지가 위에서
  아래로 이어지고, 다음 화가 자동으로 이어 붙습니다("연속 스크롤" 항목 참고).
- **페이지 넘김 모드**: 만화책처럼 한(또는 두) 쪽씩 화면 전체에 맞춰
  보여줍니다. 이 모드에서만 아래 두 컨트롤이 추가로 나타납니다.
  - **1쪽/2쪽 보기**: 한 화면에 한 쪽만 보여줄지, 스프레드처럼 두 쪽을
    나란히 보여줄지 고릅니다(기본값 1쪽). 2쪽 보기는 가로로 넓은 화면에서
    유용합니다. 2쪽 보기로 바꾸면 항상 짝수 번째 쪽(1-2, 3-4, ...)부터
    맞춰서 보여주도록 자동으로 위치를 보정합니다.
  - **읽는 방향**: "▶ 왼쪽 → 오른쪽" / "◀ 오른쪽 → 왼쪽" 버튼입니다.
    - **2쪽 보기일 때**: 한 쌍(예: 1-2쪽)에서 어느 쪽이 화면 왼쪽에, 어느
      쪽이 오른쪽에 오는지를 정합니다. 왼쪽에서 오른쪽으로 읽는 일반 만화는
      기본값(LTR — 먼저 나오는 쪽이 왼쪽), 일본 만화처럼 오른쪽에서
      왼쪽으로 넘기며 보는 작품은 RTL로 바꾸면 먼저 나오는 쪽이 오른쪽에
      옵니다.
    - **1쪽 보기일 때**: 화면 좌/우 클릭 영역과 방향키(`←`/`→`)의 다음/이전
      쪽 매핑에 반영됩니다.
    - 이 설정도 브라우저에 저장됩니다.
  - 화면의 좌/우 영역을 클릭하거나 방향키(`←`/`→`, `Space`)로 다음/이전
    쪽(2쪽 보기에서는 다음/이전 스프레드)으로 넘깁니다.
  - 현재 회차의 마지막 쪽에서 다음으로 넘기면 다음 화 첫 쪽으로, 첫 쪽에서
    이전으로 넘기면 이전 화 마지막 쪽으로 자동으로 넘어갑니다(양방향 모두
    지원 — 웹툰 모드의 자동 로드는 앞으로만 동작하는 것과 다른 점입니다).
  - 두 모드 사이를 전환하면 보고 있던 페이지 위치를 최대한 그대로 이어받아
    다른 모드에서도 비슷한 위치에서 이어 볼 수 있습니다.

## 전체화면 · 페이지 이동

- **전체화면**: 버튼을 누르면 브라우저의 전체화면 기능(Fullscreen API)이
  켜지면서 동시에 상단 내비게이션, 탭 스위치, 검색/정렬 바, 푸터가 숨겨져
  리더만 화면 전체를 씁니다. 버튼을 다시 누르거나 `Esc`를 누르면 전체화면과
  숨김이 함께 해제됩니다. 회차 목록이나 작품 목록으로 나가면 자동으로
  전체화면도 종료됩니다.
- **쪽 이동**: 숫자를 입력하고 "이동"을 누르면(또는 입력창에서 Enter) 현재
  보고 있는 회차/쪽에서 해당 페이지로 바로 이동합니다(웹툰 모드는 스크롤,
  페이지 넘김 모드는 즉시 전환).
- **화면 우하단 페이지 표시**: 지금 보고 있는 페이지가 "3 / 14" 형태로
  항상 떠 있습니다.
- **키보드 단축키** (리더가 열려 있고 입력창에 포커스가 없을 때):
  - 웹툰 모드: `Space`/`↓`/`PageDown` 아래로 스크롤, `↑`/`PageUp` 위로
    스크롤, `Home` 맨 위로, `End` 지금까지 불러온 내용의 맨 아래로.
  - 페이지 넘김 모드: `→`/`Space` 다음 쪽, `←` 이전 쪽(읽는 방향 설정에 따라
    좌우가 바뀔 수 있음), `Home` 회차 첫 쪽, `End` 회차 마지막 쪽.

## 알아두면 좋은 점 / 제한사항

- 읽음 상태·이어보기 위치는 **브라우저 로컬 저장소**에만 있습니다. 브라우저
  데이터를 지우거나 다른 브라우저/기기로 접속하면 초기화됩니다. 여러 기기에서
  진행 상태를 공유하는 기능은 없습니다.
- 최근 다운로드순 정렬은 파일 하나하나의 수정 시각이 아니라 **작품 폴더 자체의
  수정 시각**을 사용합니다. 폴더 안 파일을 수동으로 옮기거나 편집하면 정렬
  순서가 바뀔 수 있습니다.
- 연속 스크롤로 여러 회차를 한 번에 불러와도 이미지는 각 회차 원본 그대로이며,
  별도로 다시 인코딩하거나 캐시하지 않습니다 — 매번 `/files/...` 원본을 그대로
  불러옵니다.
- 전체화면 버튼은 브라우저 표준 Fullscreen API를 사용합니다. 브라우저 설정이나
  일부 임베드 환경에서 전체화면 요청이 차단되면 버튼을 눌러도 화면은 그대로일
  수 있습니다(오류 없이 조용히 무시됨) — 그 경우에도 웹툰/페이지 넘김 모드
  전환이나 쪽 이동 같은 나머지 기능은 정상 동작합니다.
- 보기 모드·읽는 방향·1쪽/2쪽 보기 선택도 이어보기 진행 상태와 마찬가지로
  브라우저 로컬 저장소에만 저장됩니다.
