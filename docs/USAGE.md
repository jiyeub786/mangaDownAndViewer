# 온라인만화뷰어 사용법

만화 게시판 사이트에서 작품의 회차 목록을 조회하고, 각 회차의 이미지를 모두 내려받아
필요하면 zip으로 압축까지 해주는 FastAPI 웹 앱입니다. 내려받은 작품은 앱 안의
"뷰어" 탭에서 바로 볼 수 있고, "온라인 보기" 탭에서는 다운로드 없이 사이트에서
바로 검색해서 읽을 수도 있습니다.

> 이 도구는 개인 소장/백업 목적의 학습용 크롤러입니다. 대상 사이트의 이용약관과
> 저작권을 반드시 확인하고 준수한 상태에서 사용하세요.

## 1. 설치

```bash
# 가상환경은 이미 .venv 로 준비되어 있다고 가정합니다.
.venv\Scripts\pip.exe install -r requirements.txt   # Windows
# 또는
.venv/bin/pip install -r requirements.txt           # macOS/Linux
```

## 2. 서버 실행

```bash
.venv\Scripts\python.exe -m uvicorn app.main:app --reload   # Windows
# 또는
.venv/bin/python -m uvicorn app.main:app --reload           # macOS/Linux
```

브라우저에서 `http://127.0.0.1:8000` 접속.

- API 문서(Swagger UI)는 `http://127.0.0.1:8000/docs` 에서 자동 제공됩니다.

## 3. 작품 검색으로 작품 ID 찾기

작품 ID(`is=`)를 직접 알아내지 않아도, "작품 검색" 카드에서 제목으로 찾을 수
있습니다.

1. 먼저 아래 "새 다운로드 작업" 카드의 **사이트 주소**를 입력합니다(검색도
   이 주소를 사용합니다).
2. "작품 검색" 카드의 입력창에 제목을 입력하고 "검색" 버튼을 누르거나
   Enter를 칩니다.
3. 검색 결과 목록(제목 + 태그)에서 원하는 작품을 클릭하면 아래 폼의
   **작품 ID**와 **작품 제목** 칸이 자동으로 채워집니다.
4. 이어서 시작/끝 페이지를 정하고 "다운로드 시작"을 누르면 됩니다.

이 검색은 대상 사이트가 자체 검색창에서 쓰는 것과 같은 요청을 서버가 대신
호출해서 보여주는 것입니다(브라우저가 직접 그 사이트로 요청하면 CORS 문제로
막히기 때문입니다). **일반 웹툰 게시판(`toons`) 결과만 지원**하며, 사이트에
있는 다른 종류의 게시판(순정만화 등) 결과는 검색 목록에 아예 나타나지
않습니다 — 이 앱의 다운로드 로직 자체가 `toons` 게시판 구조만 지원하기
때문입니다.

## 4. 웹 화면에서 다운로드 시작하기

"새 다운로드 작업" 카드에 아래 값을 입력합니다(위 검색으로 작품 ID·제목을
채웠다면 시작/끝 페이지만 정하면 됩니다).

| 항목 | 설명 | 예시 |
|---|---|---|
| 사이트 주소 | 대상 사이트의 기본 URL. `http(s)://` 포함, 끝에 `/` 없이 | `http://103.204.13.68:8905` |
| 작품 ID (`is=`) | 목록/상세 페이지 URL의 `is=` 파라미터 값 | `34978` |
| 작품 제목 | 저장 폴더명 및 zip 파일명으로 사용 | `슈퍼 뒤에서 담배 피우는 두 사람` |
| 시작 페이지 / 끝 페이지 | 목록 페이지 범위(둘 다 포함). 최신 페이지부터 오래된 페이지 순으로 순회하며, 각 페이지 내 회차는 오래된 순으로 번호가 매겨집니다 | 시작 `1`, 끝 `5` |
| 회차별로 폴더 나누기 | 체크 시 회차마다 하위 폴더 생성, 해제 시 한 폴더에 순번으로만 저장 | 기본 켜짐 |
| 완료 후 zip으로 압축 | 체크 시 다운로드 완료 후 자동으로 zip 생성 | 기본 켜짐 |

"다운로드 시작"을 누르면 작업이 백그라운드에서 실행되고, 오른쪽 "작업 목록"에
카드가 나타납니다. 카드에는 다음이 실시간(2초 간격 폴링)으로 표시됩니다.

- 상태 배지: 대기중 → 진행중 → 완료 / 실패 / 중단됨
- 처리한 회차 수, 다운로드 성공/실패 이미지 수
- 진행 로그 (회차별 이미지 목록 조회, 다운로드 실패/재시도 등)
- 완료 후 "zip 다운로드" 버튼 (zip 압축을 선택한 경우)
- 진행중일 때 "중단" 버튼

## 5. 뷰어에서 다운로드한 작품 보기

화면 상단 "다운로드" / "뷰어" 탭 스위치에서 "뷰어"를 누르면 `downloads/` 폴더를
스캔해서 지금까지 받은 작품을 보여줍니다.

1. **작품 목록**: 표지(각 작품 첫 회차의 첫 이미지) 카드가 그리드로 나열됩니다.
   검색창과 정렬(이름순/최근 다운로드순/이미지 많은순)로 원하는 작품을 빠르게
   찾을 수 있고, 클릭하면 해당 작품의 회차 목록으로 이동합니다.
2. **회차 목록**: 회차별 표지, 이름, 이미지 수가 카드로 나열됩니다. 클릭하면
   해당 회차를 뷰어로 엽니다.
3. **리더**: 이미지를 위에서 아래로 이어붙인 세로 스크롤 형태(웹툰 리더)로
   보여줍니다. 다음 화가 있으면 스크롤만으로 자동으로 이어서 불러오고, 상단
   고정 바에서 "목록으로", "이전 화" / "다음 화", 몰입 모드, 쪽 이동을 쓸 수
   있습니다.

한 번 열어본 작품·회차는 읽음 상태와 마지막 위치가 저장되어 "이어보기"로
바로 돌아갈 수 있습니다. 검색·정렬, 이어보기/읽음 표시, 연속 스크롤, 몰입
모드·쪽 이동의 자세한 동작은 [`docs/VIEWER_FEATURES.md`](VIEWER_FEATURES.md)를
참고하세요.

새로 다운로드를 완료한 뒤 뷰어에 바로 반영되지 않으면 우측 상단 "새로고침"
버튼을 누르세요(뷰어는 폴링하지 않고 진입/새로고침 시점에만 `downloads/`를
다시 스캔합니다).

다운로드 시 "회차별로 폴더 나누기"를 껐던 작품(평면 구조, 파일명이
`001_001.jpg`처럼 저장된 경우)도 파일명 앞자리 숫자를 기준으로 자동으로
회차 단위로 다시 묶어서 보여줍니다.

## 6. 작품 ID(`is=`) 직접 찾는 방법 (검색이 안 될 때)

대상 사이트에서 작품 상세/목록 페이지를 열면 주소창에 다음과 같은 형태의 URL이 보입니다.

```
{사이트주소}/bbs/board.php?bo_table=toons&is=34978
```

여기서 `is=` 뒤의 숫자가 작품 ID입니다.

## 7. 다운로드 결과물 위치

서버 실행 위치 기준 `downloads/{작품 제목}/` 아래에 이미지가 저장됩니다.
zip 압축을 선택한 경우 `downloads/_zips/{작품 제목}.zip` 에 압축 파일이 생성되고,
웹 화면의 "zip 다운로드" 버튼으로 그대로 내려받을 수 있습니다.

## 8. 온라인 보기 — 다운로드 없이 바로 읽기

"온라인 보기" 탭은 파일을 저장하지 않고 사이트에서 바로 검색해서 읽는 기능입니다.
**다운로드 기능과는 완전히 별개**로 동작합니다 — 여기서 무엇을 봐도 `downloads/`에는
아무것도 생기지 않고, 다운로드 작업 목록에도 나타나지 않습니다.

1. 사이트 주소를 입력하고 제목으로 검색합니다(다운로드 탭의 검색과 동일한 방식,
   `toons` 게시판만 지원).
2. 결과를 클릭하면 회차 목록이 뜹니다. 목록은 **사이트가 보여주는 순서 그대로**
   (보통 최신 회차부터)이고, 사이트의 목록 페이지 단위로 나뉘어 있어 "이전/다음
   페이지" 버튼으로 넘길 수 있습니다.
3. 회차를 클릭하면 뷰어 탭과 같은 방식의 리더(웹툰 세로 스크롤 / 페이지 넘김,
   읽는 방향, 1·2쪽 보기, 전체화면, 쪽 이동, 키보드 단축키)로 바로 읽을 수
   있습니다. 보기 모드·읽는 방향·1·2쪽 설정은 뷰어 탭과 같은 값을 공유합니다.

**뷰어 탭과 다른 점**:
- 회차가 자동으로 이어지는 범위는 **지금 불러온 목록 페이지 안**으로 한정됩니다.
  다른 목록 페이지의 회차로 넘어가려면 회차 목록 화면으로 돌아가 페이지를
  이동해야 합니다(뷰어 탭은 다운로드해 둔 전체 회차를 이미 알고 있어서 이 제약이
  없습니다).
- "이어보기"·읽음 표시 같은 진행 상태 저장은 없습니다.

## 9. REST API로 직접 사용하기

웹 화면 없이 API만 호출해 자동화할 수도 있습니다.

**작업 생성**

```bash
curl -X POST http://127.0.0.1:8000/api/jobs \
  -H "Content-Type: application/json" \
  -d '{
        "site_url": "http://103.204.13.68:8905",
        "toon_id": 34978,
        "title": "작품 제목",
        "start_page": 1,
        "end_page": 3,
        "separate_folders": true,
        "make_zip": true
      }'
```

응답의 `id` 값이 작업 ID입니다.

**작업 상태 조회**

```bash
curl http://127.0.0.1:8000/api/jobs/{job_id}
```

**작업 목록 조회**

```bash
curl http://127.0.0.1:8000/api/jobs
```

**작업 중단**

```bash
curl -X POST http://127.0.0.1:8000/api/jobs/{job_id}/stop
```

**zip 다운로드**

```bash
curl -OJ http://127.0.0.1:8000/api/jobs/{job_id}/download
```

**작품 검색 API**

```bash
curl -G http://127.0.0.1:8000/api/search \
  --data-urlencode "site_url=http://103.204.13.68:8905" \
  --data-urlencode "query=나루토"
```

`toons` 게시판 결과만 `[{"id":..,"title":..,"tags":..,"description":..}]`
형태로 반환됩니다.

**뷰어(라이브러리) API**

```bash
# 다운로드한 작품 목록
curl http://127.0.0.1:8000/api/library

# 특정 작품의 회차 목록
curl http://127.0.0.1:8000/api/library/{작품제목}

# 특정 회차의 이미지 URL 목록
curl http://127.0.0.1:8000/api/library/{작품제목}/episodes/{episode_id}/images
```

이미지 URL은 `/files/...` 아래에서 정적으로 제공되며, 응답에 담긴 URL을 그대로
브라우저나 `curl`로 열면 됩니다.

**온라인 보기 API** (다운로드 없이 실시간 조회, `downloads/`에 아무것도 안 남음)

```bash
# 특정 작품의 회차 목록 (페이지 단위, 기본 page=1)
curl -G http://127.0.0.1:8000/api/online/episodes \
  --data-urlencode "site_url=http://103.204.13.68:8905" \
  --data-urlencode "toon_id=4" \
  --data-urlencode "page=1"

# 특정 회차의 이미지 URL 목록 (사이트 원본 URL 그대로)
curl -G http://127.0.0.1:8000/api/online/images \
  --data-urlencode "site_url=http://103.204.13.68:8905" \
  --data-urlencode "toon_id=4" \
  --data-urlencode "wr_id=428"
```

여기서 반환되는 이미지 URL은 `/files/...`가 아니라 **사이트 원본 URL 그대로**입니다
— 서버가 다운로드해 중계하는 게 아니라 브라우저가 사이트 이미지를 직접 불러옵니다.

## 10. 주의사항 / 제한사항

- **대상 사이트 한정**: 이 크롤러는 `/bbs/board.php?bo_table=toons` 게시판 구조와
  상세 페이지의 `var img_list = [...]` 스크립트 변수를 전제로 동작합니다. 다른 구조의
  사이트에는 그대로 사용할 수 없습니다 (`app/crawler.py` 수정 필요).
- **작업 상태는 메모리에만 저장**됩니다. 서버를 재시작하면 이전 작업 목록/로그는
  사라집니다(다운로드된 파일 자체는 `downloads/`에 그대로 남아 있습니다).
- **동시 실행**: 여러 작업을 동시에 시작할 수 있지만, 대상 사이트에 부담을 주지
  않도록 과도한 동시 실행은 피하세요.
- **로컬/개인 사용을 전제**로 인증이나 접근 제어가 없습니다. 외부에 노출되는
  네트워크에 그대로 띄우지 마세요.
- **뷰어는 `downloads/`를 읽기 전용으로 스캔**할 뿐, 별도 DB나 캐시를 쓰지
  않습니다. 파일을 수동으로 옮기거나 지워도 다음 스캔에 바로 반영됩니다.
- **작품 검색은 대상 사이트의 비공식 내부 API**(`/bbs/ajax.search.php`)에
  의존합니다. 사이트가 그 구조를 바꾸면 검색이 예고 없이 깨질 수 있고, 이때는
  6번 항목처럼 URL에서 작품 ID를 직접 찾아 입력하면 됩니다. `toons` 게시판이
  아닌 결과는 애초에 목록에 나타나지 않습니다.
- **온라인 보기는 서버에 아무 상태도 남기지 않습니다** — 매번 사이트를 다시
  호출해서 보여줄 뿐, 다운로드 작업 큐(`/api/jobs`)와도, 뷰어 라이브러리
  (`downloads/`)와도 완전히 분리되어 있습니다. 진행 상태 저장이나 "이어보기"는
  없습니다.
