# Changelog

이 파일은 [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/) 형식을 참고해
온라인만화뷰어(FastAPI 웹 버전)에 추가/변경된 기능을 기록합니다. 버전 번호는 릴리스
태그가 아니라 기능 단위 마일스톤 구분용입니다.

## [0.7.0] - 2026-08-30

### Added
- **온라인 보기 탭**: 다운로드 없이 사이트에서 바로 검색하고 읽는 새 탭.
  검색 → 회차 목록(사이트 페이지 단위) → 리더(웹툰 세로 스크롤 / 페이지 넘김,
  읽는 방향, 1·2쪽 보기, 전체화면, 쪽 이동 — 뷰어 탭과 같은 리더 기능).
  이미지는 사이트 원본 URL을 브라우저가 직접 불러오며(핫링크 제한 없음을
  확인함), 서버가 다운로드하거나 저장하지 않습니다.
- `GET /api/online/episodes?site_url=&toon_id=&page=`,
  `GET /api/online/images?site_url=&toon_id=&wr_id=` API 추가. 새 모듈
  `app/online.py`가 처리하며, 다운로드 작업 파이프라인(`app/jobs.py`,
  `crawler.crawl_toon`)과는 완전히 분리되어 있습니다 — 파일을 쓰지 않고,
  작업 목록에도 나타나지 않습니다.

### Fixed
- 다운로드 탭 작품 검색 결과 목록에 의도했던 간격/스크롤 제한 스타일이
  적용되지 않던 문제 수정(컨테이너에 `.search-results` 클래스가 빠져 있었음).

## [0.6.0] - 2026-08-30

### Added
- **작품 검색**: 다운로드 탭에 검색 카드 추가. 대상 사이트의 자체 검색
  기능(비공식 `/bbs/ajax.search.php` 엔드포인트)을 서버가 대신 호출해
  제목으로 작품을 찾고, 결과를 클릭하면 작품 ID·제목이 다운로드 폼에
  자동으로 채워집니다. 작품 ID를 URL에서 직접 찾지 않아도 됩니다.
- `GET /api/search?site_url=&query=` API 추가(REST로 직접 호출 가능).

### Changed
- 검색 결과는 **`toons` 게시판만** 지원합니다 — 사이트 검색이 함께 반환하는
  다른 게시판(`cartoonson`) 결과는 이 크롤러가 다운로드할 수 없어 목록에서
  아예 제외됩니다.

## [0.5.0] - 2026-08-30

### Fixed
- 웹툰 모드와 페이지 넘김 모드를 오갈 때 두 화면이 겹쳐 보이던 문제 수정.
  원인은 `hidden` 속성이 있어도 같은 요소에 걸린 author CSS의 `display` 선언
  (`.btn`, `.viewer-controls`, `.reader-strip` 등)이 origin 우선순위로 이겨서
  실제로는 안 숨겨지던 것 — `[hidden] { display: none !important; }`을
  전역으로 추가해 해결. 이 버그 때문에 회차 목록/리더에서도 작품 검색창이
  계속 보이면서 "검색이 안 먹는다"처럼 보이던 문제도 함께 해결됨.
- 회차 목록 화면에서 검색창이 아무 동작도 하지 않던 문제 수정(위와 같은 원인).

### Added
- 회차 목록 화면에서 검색창이 **회차 이름 검색**으로 동작(예: `006` 입력 시
  "006화" 등만 표시). 정렬 드롭다운은 이 화면에서 숨김.
- 회차 목록 화면과 리더 상단 바에 **"← 라이브러리" / "라이브러리" 버튼**
  추가 — 몇 단계에 있든 클릭 한 번으로 작품 목록으로 바로 이동.
- 페이지 넘김 모드에 **1쪽/2쪽 보기** 토글 추가. 2쪽 보기는 스프레드처럼
  두 쪽을 나란히 보여주며, 항상 짝수 쪽 경계에 맞춰 정렬됩니다.

### Changed
- 읽는 방향(LTR/RTL) 설정의 역할을 명확히 함: **2쪽 보기에서 쌍의 어느 쪽이
  왼쪽/오른쪽에 오는지**가 주 용도이고, 1쪽 보기에서는 기존처럼 클릭 영역·
  방향키 매핑에 사용됩니다.

## [0.4.0] - 2026-08-30

### Added
- 리더 보기 모드 전환: **웹툰(세로 스크롤)** ↔ **페이지 넘김(만화책 방식)**.
  선택값은 브라우저에 저장되어 다음에 리더를 열 때도 유지됩니다.
- 페이지 넘김 모드 전용 **읽는 방향 설정**(왼쪽→오른쪽 / 오른쪽→왼쪽) — 클릭
  영역과 좌우 방향키의 다음/이전 쪽 매핑에 반영됩니다.
- 페이지 넘김 모드는 회차 경계를 **양방향**(다음 화뿐 아니라 이전 화도)으로
  자유롭게 넘나듭니다.

### Changed
- "몰입 모드"를 브라우저 표준 **Fullscreen API** 기반 전체화면으로 전환.
  `Esc`로 브라우저가 직접 전체화면을 종료해도 UI 상태가 자동으로 맞춰집니다.

## [0.3.0] - 2026-08-30

### Added
- 작품 목록 **검색 · 정렬**(이름순 / 최근 다운로드순 / 이미지 많은순).
- **이어보기 · 읽음 표시** — 브라우저 로컬 저장소 기반 읽기 진행 상태 저장.
- 리더 **연속 스크롤**: 다음 화 자동 로드, 회차 구분선, 헤더·브레드크럼 자동
  갱신.
- 몰입 모드(초기 버전), 쪽 이동, 화면 우하단 페이지 인디케이터, 키보드 스크롤
  단축키.

### Changed
- `TitleInfo`에 `updated_at`(작품 폴더 수정시각) 필드 추가 → "최근
  다운로드순" 정렬에 사용.

## [0.2.0] - 2026-08-30

### Added
- **뷰어 탭**: 다운로드받은 작품을 브라우저에서 바로 보는 기능.
  - 작품 목록 → 회차 목록 → 세로 스크롤(웹툰) 리더.
  - `app/library.py`: `downloads/`를 읽기 전용으로 스캔, "평면" 다운로드
    구조(폴더 없이 파일명 접두사로만 회차가 구분되는 경우)도 회차 단위로
    자동 재그룹핑.
  - `/api/library`, `/api/library/{title}`,
    `/api/library/{title}/episodes/{episode_id}/images`, `/files/*` 엔드포인트
    추가.

## [0.1.0] - 2026-08-30

### Added
- 기존 단일 스크립트(`cwraling_download_manga_img_site2.py`)를 **FastAPI 웹
  앱**으로 재구성.
  - `app/crawler.py`: 크롤링/다운로드/압축 로직을 함수 단위로 정리, 무한
    재귀 재시도 제거, Bandizip 의존 대신 표준 라이브러리 `zipfile` 사용.
  - `app/jobs.py`: 인메모리 작업 큐 + 백그라운드 실행, `/api/jobs` 로 진행
    상황을 2초 간격 폴링해 보여주는 UI.
  - `design.md`(Binance 스타일: 다크 캔버스 + 단일 옐로 액센트) 기반 디자인
    시스템 적용.
  - 사용법 문서(`docs/USAGE.md`) 작성.
